## Quick Reference

### Mathematical Formulas
- Sum of first n natural numbers: `n(n+1) / 2`
- Good pairs from n occurrences: `n * (n-1) / 2`
- Bitwise shifting: `Number << k = Number * 2^k`

- HashMap for frequency counting
